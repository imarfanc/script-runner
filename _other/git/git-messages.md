data/output/, so one-off sends meant manually dropping a file into that
folder first. Uploads now land in a gitignored chosen/ bucket under
.runtime/ and are merged into the same file list the composer already shows,
and pasting an image now hands WhatsApp real bitmap data instead of a file
URL, which it was silently rejecting.
