The old `ansi()` helper only mapped a handful of SGR codes to fixed CSS classes, so anything a real
script printed — bold, dim, 256-colour, truecolor, or box-drawing output with no colour at all —
either lost its styling or rendered wrong. `ansi.js` replaces it with a proper SGR parser plus a
fallback reading for plain Gum-style output. Double-click also conflated "open" and "run", which
made it easy to relaunch a script by accident; a click now just opens or focuses the window, and a
dedicated play button is the only thing that starts a run.
